# Anargya official asset inventory

Collected: **8 October 2026 (Asia/Jakarta)**. Scope: publicly served images linked by rendered pages on the official website. Status: inventory complete; Figma creation awaiting approval.

## Retrieval and provenance

**66 unique image files**, approximately **94.6 MiB**, saved in `public/images/anargya/`. Original bytes were preserved; no image was recolored, cropped, enhanced, or re-encoded. Duplicate carousel instances were downloaded once. Filenames keep recognizable original names, with category prefixes and lowercase normalization where useful. Each image was decoded locally and checked for dimensions; selected photo/logo groups were visually reviewed as contact sheets.

The site uses Next.js optimized image URLs. The original source URLs below were recovered from the `url` parameter of rendered image elements; they are public files, not guessed paths. External Graphassets URLs were explicitly embedded by official news pages. No authentication, access-control bypass, private storage enumeration, or restricted download was used.

**Licensing is unresolved:** the inspected site footer states copyright 2026 Anargya ITS EV Team. No explicit open image license, reuse permission, photographer credit, or logo-use grant was visible in the inspected pages. Public accessibility and retrieval do not establish unrestricted rights. These are official-source candidates for this Anargya project, not certified rights-cleared assets.

## Recommended selection for later Figma design

- **Identity:** `logo-polos.png` for the header symbol; `logo-anargya-inline.png` for a fuller footer/identity treatment. No official SVG/vector logo was retrieved; do not trace or invent one as an official master.
- **Hero:** prefer `gl-mk-6-car.png` with `gl-mk-6-car-mobile.png` for a genuine Mark 6.0 vehicle scene; `hero-firstslide-*` provides existing official composition if its baked-in artwork fits. New copy must remain native text.
- **Vehicle showcase:** `mk6-side-left.png`, `mark5.png`, and `mark-4-car.png`; names follow source captions. Mark 6.0 specifications remain unavailable.
- **Research:** `fsae-j-4.jpg`, `fsae-j-3.png`, `anr-testing.png`, and `testing-mk-6.png` show vehicle preparation/testing. `fsae-j-presentation.png` supports a business-presentation story, not a claimed technical lab activity.
- **Team:** `about-us-team.webp` is a group scene; `contact-jumbotron.jpg` is an event group photograph. `bg-team.png` has generation-specific baked-in artwork and should not represent an undated current roster.
- **Partners:** retain each logo's natural aspect ratio; use image fills with contain sizing. Avoid uniformly recoloring partner brands to green. Resolve SDI/507 Power and Bodok/Badak labels before display.
- **Achievements:** use the graphic as a reference only; verified labels/results must become native text. Resolve the PR Award year conflict first.
- **News:** use article-specific media for that article only. Grab riders and Honda signage must not be labeled as Anargya testing or team photos.
