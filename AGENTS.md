## Anargya Research Team — Project Instructions

This project is an Anargya ITS EV Team website built using Next.js, TypeScript, and Tailwind CSS.

The website design must be created in Figma before frontend implementation begins.

### Required Reference Files

For any Figma design or website UI task, read:

1. `docs/figma-instructions.md` — Main project workflow and design objectives.
2. `docs/anargya-design.md` — Authoritative Anargya design system.
3. `docs/sapu-angin-design.md` — Sapu Angin reference design system.

Sapu Angin reference website:
https://www.itsteamsapuangin.com/

### Design Priorities

1. Always follow Anargya's official design system for branding, colors, fonts, and defined component styles.
2. Use Sapu Angin for layout inspiration, visual composition, component architecture, and interaction patterns.
3. Preserve Anargya's distinct visual identity.
4. Do not directly copy Sapu Angin's branding or proprietary assets.
5. Prefer reusable, editable Figma components over flattened images.

### Workflow

1. Analyze both design systems and the reference website.
2. Save the design analysis to `docs/design-analysis.md`.
3. Wait for approval before creating the Figma design.
4. Create the Figma design incrementally.
5. Do not implement or modify the Next.js website until explicitly requested.

### Efficiency Rules

- Do not repeat completed analysis unnecessarily.
- Reuse `docs/design-analysis.md` whenever possible.
- Make targeted changes instead of recreating completed designs.
- Keep responses concise and report meaningful progress.
- Ask for clarification only when essential information is missing.
